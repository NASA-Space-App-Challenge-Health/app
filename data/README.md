# Planned health-data sources

Nothing in this folder is loaded into PostgreSQL. The running dashboard uses
simulated crew and simulated readings generated by
`backend/services/api/app/seed.py`.

Put future raw downloads in `data/raw/` and derived tables in `data/processed/`.
Those directories are gitignored except for `.gitkeep`. Do not commit large
study files, credentials, or real medical records.

| Source | Role in the monitor | Where to start | Configuration later |
| --- | --- | --- | --- |
| [OSD-575](https://osdr.nasa.gov/bio/repo/data/studies/OSD-575) | NASA OSDR Inspiration4 metabolic panel. Candidate measurements for blood glucose and related chemistry. | Open the study in OSDR and confirm the file you are allowed to use. | Accept NASA's data-use terms in the browser if the study requires it. No key is stored in this repo. |
| [OSD-569](https://osdr.nasa.gov/bio/repo/data/studies/OSD-569/) | NASA OSDR Inspiration4 blood counts. Candidate measurements for white cells, red cells, hemoglobin, and platelets. | Same as OSD-575. | Same data-use step. No key is stored in this repo. |
| [RadLab API](https://visualization.osdr.nasa.gov/radlab/api/) | NASA RadLab ISS dosimetry. Candidate source for radiation dose instead of the simulated cumulative mSv figure. | Read the API index before choosing an endpoint. | No key is stored in this repo. |
| [DONKI SEP](https://ccmc.gsfc.nasa.gov/DONKI-API/get/SEP) | NASA DONKI solar energetic particle events. Context for radiation risk, not a crew dosimeter. | The published SEP route takes a date range and an `api_key`. | `DEMO_KEY` is enough for a light demo. Request a key from <https://api.nasa.gov> if you exceed that quota. Keep the key in an untracked env file. |

Confirm column layouts and units from the upstream files before mapping them
onto `health_readings`. Keep `source` values honest: today's allowed values are
`simulated` and `manual` only. Add a new source in a forward migration when a
real feed is actually wired.
